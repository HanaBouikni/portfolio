# Portfolio — Hana Bouikni

Site portfolio personnel présentant mon parcours entre **cybersécurité** et **design UI/UX** : compétences, projets, galerie de design, certifications et événements.

**Site en ligne :** https://portfolio-psi-woad-40.vercel.app

## Sections

| Section | Contenu |
|---------|---------|
| Accueil | Présentation et accès rapide aux projets |
| À propos | Parcours : design graphique, UI/UX et sécurité |
| Compétences | Python, HTML/CSS, Figma… |
| Projets | Projets de cybersécurité (messagerie chiffrée RSA + AES sur le modèle PGP) et projets web |
| Galerie | Travaux de design graphique, avec aperçu en fenêtre modale |
| Certifications et événements | Certifications, hackathons, idéathons et conférences |
| Contact | Liens et formulaire de contact |

## Technologies

- **HTML5 / CSS3** : mise en page responsive, animations d'arrière-plan
- **JavaScript** (sans framework) : navigation, fenêtres modales, animations au défilement
- **Vercel** : hébergement

## Lancer en local

Aucune installation n'est nécessaire : ouvrez `index.html` dans un navigateur.

```
portfolio/
├── index.html
├── styles.css
├── script.js
└── image/
```
